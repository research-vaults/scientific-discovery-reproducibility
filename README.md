# Toward a Computational Theory of Scientific Discovery

Reproducibility release **2026-10-02**, accompanying a position paper about capability growth, target success, procedure availability and validated completion. This package contains fixed-analysis code, reference results and anonymous LaTeX sources from the **2026-09-30 development revision**. It is not a replacement for a conference submission. The compiled paper is not distributed here.

The analyses report conditional examples and retrospective prediction boundaries, including adverse results. They do not validate a calendar of scientific breakthroughs, a universal complexity scale or a clinical prediction.

## Setup and reproduction

Python 3.11 and TeX Live with `latexmk` are required for the complete build. No API keys, paid model calls or wet-lab experiments are used.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/fetch_sources.py
python scripts/build_paper.py
```

Run in a disposable checkout: reproduction overwrites generated tables, figures and numerical results. Source downloads require internet access; the analysis/build then runs locally. `fetch_sources.py` rejects input files whose SHA-256 differs from the recorded source. If an upstream URL changes, stop and obtain the exact recorded version rather than silently substituting new data.

To compile the source using supplied figures/tables without rerunning analyses:

```sh
cd manuscript
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=build paper.tex
```

The source revision has 9 main/disclosure pages, 4 reference pages and 17 appendix pages. This release does not certify current venue formatting or anonymity. A website-linked public repository is not an anonymous reviewer artifact.

## Inputs, outputs and checks

- `evidence/review_remediation_2026-09-19/sources/ObsScaling/`: public aggregate model scores from [ObsScaling](https://github.com/ryoungj/ObsScaling), commit `4d6e1e43fd2635d04654aa77d1df9d5266ea0382`; Apache-2.0 license retained.
- `SOURCE_DATA.json`: [GOLLuM](https://github.com/schwallergroup/gollum) commit and file checksums. Chemistry CSV inputs and generated raw-outcome traces are **not redistributed**; the fetch command reconstructs them locally. Consult upstream dataset terms before use; a code-repository license alone does not settle all data rights.
- `METR_INPUTS.json`: retrieval URLs and checksums for the historical [METR](https://metr.org/) diagnostic. The website YAML is not redistributed because an explicit redistribution license was not established.
- `scripts/`: source-score/target-descriptor holdouts, exact identification/cost calculations, fixed-table chemistry replay, endpoint/horizon sensitivities, independent checks, table/figure rendering and build entrypoint.
- `evidence/*/results/`: reference aggregate scores, predictions and sensitivity results. The chemistry replay regenerates its detailed raw-outcome traces locally before later checks; no model-chat logs are included.
- `manuscript/figures/`: manuscript-ready plots and tables. `manuscript/build/paper.pdf` and `manuscript/paper.pdf` are generated by the build.

The retained directories have historical names to preserve script paths; they contain scientific inputs/results, not private reviews. `check_*.py`, `reconstruct_main_evidence.py` and `verify_horizon_specification.py` run as part of the build. Two checks of internal planning/review-file hashes were removed from this export; scientific contract, arithmetic and source checks remain. See `EXPORT_PROVENANCE.json`, `VALIDATION.md` and `SHA256SUMS`.
